The 50 environments, one by one

In each environment an AI agent has a task and a rule. There is an honest route that follows the rule and a loophole that only follows it under a narrow reading. Making the honest route costly tests whether the agent starts reading the rule narrowly.

What the baseline runs show

Five models ran all 50 environments, each environment in both versions (cheap and costly honest route) and at all three pressure levels, one run per cell: 1500 runs. A run counts as a loophole when the environment's own state shows the loophole action was taken, whatever the agent said.

The plots above vary one thing at a time. Here the runs are fitted together, so that each factor is read with the others held fixed. Standard errors are clustered by task, because the runs of one task are not independent. An odds ratio of 2 means the odds of the loophole double.

What it says

  • Cost is the largest factor. A costly honest route multiplies the odds of the loophole by 5.3 (interval 3.4 to 8.2), about 29 percentage points on average, with model, pressure, environment kind and domain held fixed. In 42 of the 50 tasks the loophole is more common when costly, in 8 equal and in 0 less common.
  • Pressure matters too. Each step from P1 to P3 multiplies the odds by 1.54 (about 7 points per step), and the effect is stronger when the route is costly (interaction 1.25, p = 0.029). These pressure levels mix time limits and money, so this is not a test of reputation stakes alone.
  • Models differ. Against GLM 5.3, Kimi K3.1 Pro has 2.1 times the odds of the loophole, Qwen 3.8 Max 0.6 and DeepSeek V4.1 Flash 0.6. Models also ran on different dates and environment releases, so part of this may not be the model.
  • The cost effect is smaller when the honest route can still make the deadline. In the six environments where it lands within minutes, the cost effect is 0.30 times that of the deadline-missed environments (p = 0.007). That fits the deadline, not only the effort, driving part of the shift. The five money-only environments still show a rise (16% to 41%), but five tasks give wide intervals.
  • Cost makes agents give up. A costly route multiplies the odds of taking neither route by 10.7; this is also higher in the money-only environments (3.6 times).
  • The loophole saves effort. When the route is costly, compliant runs make 41 tool calls on average and loophole runs 23. When cheap, both make about 22.
  • Mentioning the rule does not tell the routes apart. 97% of runs mention the rule in their reasoning, loophole runs as often as compliant ones. With the other factors held fixed, more rule words per step has an odds ratio of 0.82 (p = 0.22). What the model concludes has to be read in the trajectory.

Limits: one run per model, task, version and pressure level; 50 tasks; a keyword match counts rule words, not conclusions; the stakes and deadline designs are those of the first 50 environments, which the later no-deadline design replaces. These are associations in a single set of runs, not a controlled experiment.
